# 8：搜索输入被自动查找打断

状态：已关闭，2026-10-19，交付见 [close](close.md)。

## 原始需求

> emd 搜索框 issue：键入字母后，会在亚秒级内自动把这个片段输入当作搜索目标，然后搜索框失去焦点，用户不能再继续输入文本。这是高亮重新渲染跟键入状态产生了竞态？

## 目标与验收

保留输入后自动查找的行为，查找完成后用户仍可连续输入，不需要再次点击输入框。输入值、光标与选区保持正确；Enter、Shift+Enter 和上下匹配按钮继续工作。清空或关闭查找后清除匹配。

需要区分 Markdown 排版更新与 Electron 原生查找的焦点行为，以复现结果确定最小修复。实施决策见 [ADR](adr.md)，验证路线见 [route](route.md)。
