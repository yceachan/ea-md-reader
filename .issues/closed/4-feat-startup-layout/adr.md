# ADR-004：设置驱动的一次性 KDE 启动布局

状态：已实施并关闭。需求和边界归属 [issue](issue.md)，编辑器协议归属 [ADR-003](../3-feat-external-editor/adr.md)，最终交付见 [close](close.md)。

## 设置与计数

共用用户数据目录的 `setting.toml`，`[startup].layout` 只接受 `default` / `focus`。主进程读写，经受限 preload 接口向界面提供偏好；使用临时文件替换，保留编辑器、profile 等分区。缺省值为 `default`；损坏文件或非法值明确报错。首版没有命令行覆盖、窗口历史或屏幕偏好。

`focus` 使用启动进程 pwd 的当前层普通文件数，复用 Reader 的 Markdown 和 HTML 扩展名集合。计数不递归，工作树展示沿用既有递归扫描。无参数不会因计数自动打开文档。

| 模式 / 文档数 | 宽度 | 初始面板 |
| --- | --- | --- |
| default，任意数量 | 1180，工作区不足时缩小 | 双面板展开 |
| focus，0 | 同 default | 双面板关闭 |
| focus，1 | 最小宽度 620 | 双面板关闭 |
| focus，至少 2 | 工作区宽度的一半，向下取整 | 工作树开启、TOC 关闭 |

默认模式与零文档使用最高 850 的高度并居中；专注模式有文档时使用工作区全高度并右侧停靠。最小高度为 440，尺寸均为鼠标屏幕工作区的逻辑像素。工作区无法容纳目标最小尺寸时报告错误，保留可用应用窗口。保存设置不改变当前窗口；第二实例仍只打开文件与唤回已有窗口。

## 平台执行

共享主进程调用 Linux 平台的启动能力。KDE X11 使用 Electron 屏幕接口；KDE 原生 Wayland 使用 KWin 脚本和随包提供的 Qt D-Bus 桥接程序。非 KDE 平台保持原有普通窗口行为，启动布局选择明确标记 TODO。

参考 fsearch_drawer 的 `workspace.screenAt(workspace.cursorPos)`、`clientArea`、`sendClientToScreen` 与 `frameGeometryChanged` 确认过程。每次启动先捕获鼠标所在输出的工作区，再创建主窗口；按本次进程 PID 匹配普通窗口，排除对话框和 transient 窗口。只设置本次主窗口的输出与几何，几何确认前将其 opacity 设为 0，确认后恢复。没有复制参考项目的全局快捷键、常驻置顶和持续纠偏行为。

Node 与 KWin 使用同一个几何计算函数。原生脚本由独立请求名加载，D-Bus 返回 context / applied / error；桥接结束后卸载自己加载的脚本，主进程删除临时目录。脚本与桥接均有有限超时，主窗口关闭时结束请求。错误通过应用现有错误界面报告，并记录在启动日志。文档计数和面板意图先确定，再执行窗口定位；定位失败不改变已经确定的面板状态。

KWin 传回工作区宽度用于启动面板展示判断，并按应用 zoomFactor 换算 CSS 宽度；不重复乘设备像素比。原生 Wayland 首版不持续订阅跨屏输出变化。

## 面板与欢迎页

用户开关与宽度展示模式分开处理。专注多文档在欢迎页也持有明确的 pwd 根目录，读取工作树并支持打开文件；没有活动标签不意味着不能访问工作树。专注布局允许工作树缩至已有最小面板宽度，为阅读区域留出空间。

窗口不超过所在屏幕工作区半宽时，TOC 必须使用右覆盖层，以保留正文宽度。超过半宽时仍需要满足正文剩余空间才能停靠。此规则适用于两种启动模式。工作树空间不足时使用左覆盖层，覆盖层互斥并脱离正文布局流。选择有效 TOC 锚点或成功打开文件后收起，失败保留错误与面板；支持 Esc、遮罩、关闭按钮及焦点恢复。TOC 开关由独立 `TocDock` 组件提供，绝对定位在面板左边缘的外侧并垂直居中，随面板宽度变化保持吸附，不占目录内容列；关闭时在右侧预留入口中显示。圆角、渐变高光、边缘描边与阴影体现立体层次，悬停及按压反馈使用同一配色。
