## 核心测试

设置用例覆盖文件缺失、布局字段缺失、两个合法值、非法类型、非法枚举、TOML 损坏和写入失败。分别修改布局和编辑器后重新读取，确认另一分区保留。命令行覆盖不改变文件字节，`--` 字面路径继续正确。

启动用例确认新窗口应用布局，已有窗口第二实例只打开文件。修改设置、恢复最小化窗口和切换文件不重排。普通窗口模式与右停靠模式分别检查初始面板状态。

UI 用例在 workspace 边界和屏幕半宽边界的前后各测量一次。覆盖层开关前后比较正文宽度、块位置与换行。检查 TOC 锚点定位、分支展开、workspace 成功/失败打开、Esc、遮罩、焦点恢复和两个面板互斥。

几何用例覆盖负坐标输出、不同任务栏位置、100%/125%/150%/200% 缩放、奇数工作区尺寸和跨屏移动。单位换算单元测试只验证真实几何关系，不复制整份布局实现。

## KDE 与 CI

现有 X11 UI 测试继续验证共享组件。新增 KDE Wayland 集成必须验证 KWin 真实管理的窗口，不能用 Xvfb 通过来替代。先在当前会话进行原生验证，再确定可重复的 CI 运行方式。

CI 可选独立的嵌套 KWin Wayland 会话，或有图形会话的专用运行机。嵌套环境的多输出、激活、窗口身份和尺寸要实际验证。若 CI 无法提供某项能力，单独记录未覆盖项，不把模拟脚本结果写成桌面通过。

失败保留布局请求、匹配身份、KWin 结果、实际窗口边界和 UI 截图。安装与卸载只管理应用拥有的集成文件和请求。没有管理员依赖时使用用户级目录；本轮不执行安装。

完成后在本 route 记录阶段状态、实现提交和测试链接。布局定义只维护在 ADR，验收只维护在 raw issue，不另建 README 索引。
