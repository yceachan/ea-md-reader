# ADR-002：统一顶栏图标与滚动容器责任

状态：拟定，未实施。日期：2026-10-06。需求、证据和验收以 [raw issue](issue.md) 为唯一来源。本文维护布局、图标和滚动责任决策。

## 顶栏与图标

沿用当前 React 与 CSS 结构，调整 `.toolbar` 的子元素顺序。应用 logo 复用 `assets/emd.svg` 的设计来源，不另画一个应用标识。名称保持准确的 `Ea.Md.Reader`。原有查找、目录和窗口控制仍有可见入口。

顶栏 SVG 使用同一图标组件和颜色来源。按用户修正，按钮使用白底，线条沿用主题红砖色 `--kb-accent`，强调点跟随线条颜色。悬停和选中使用淡红砖色底，禁用和焦点态沿用现有规则，不改变图标含义。

新增设置图标只负责显示设置入口。条目 3 接入桌面编辑器设置，条目 4 接入启动布局与共用存储。文件菜单中的同一设置动作及开发者控制台分组由 [ADR-006](../6-feat-devtools/adr.md)维护。原有“打开”和“另存为”继续调用原动作。

顶栏空白和名称区域继续支持窗口拖动。所有操作按钮和菜单使用 `no-drag`。窄窗口优先减少间距与隐藏路径文本，固定操作保持可访问。

## 工作区空白菜单

删除工作区顶部整行，根目录作为树的上下文信息继续显示。空白菜单绑定到覆盖整块面板空白的容器，不能只绑定在存在树节点时才出现的 `<ul>` 上。已知根目录但扫描失败或节点为空时，仍可重载。

空白处请求只传工作区根目录。文件和目录请求带明确节点目标。应用接口可以区分工作区目标与节点目标，不依靠伪造活动文件路径。主进程继续验证根目录属于已授权的工作区。

节点事件阻止冒泡，面板空白事件不重复弹出节点菜单。应用管理展开状态，使重载后的仍存目录保持展开。无法继续使用的节点和根目录状态要明确显示，不静默换到另一棵树。

工作树重载只重新扫描节点，不重读文档内容。“重新读取文件”和“重新载入工作树”是两个不同操作。文件编辑入口的具体行为由 [ADR-003](../3-feat-external-editor/adr.md) 维护。

## 高度与滚动

应用外层使用当前纵向 flex。顶栏、标签栏、查找栏和状态栏占据自身高度。工作区填充剩余高度。阅读区和活动预览的高度由同一剩余空间决定，不在两个组件各自计算屏幕高度。

标签栏采用明确的行高、按钮内容高度和边界。实际取值在测量后确定。子元素的最小高度不得撑破父容器。标签栏禁止纵向溢出，并隐藏横向原生滚动条，同时保留横向滚动能力。

隐藏滚动条不能作为 B2.1 唯一修复。实现先测量并修正容器、内容和 padding 的关系，再处理滚动条外观。活动标签变化时将它滚入视区，键盘切换和横向滚动继续可用。

Markdown 的活动文档面板负责正文纵向滚动。HTML 的外层面板与 iframe 等高，iframe 内部页面负责自己的滚动。长文档、代码块和表格的必要滚动不受标签栏样式影响。

尺寸比较允许最多 1 CSS px 的边界和取整差值。设备像素比、应用缩放和系统缩放分别记录。不能把 Playwright 缩放结果说成 HDMI 硬件复现。

## 取舍

保留现有布局可以减少对正文排版和面板拖拽的影响。统一 SVG 组件避免相同操作出现不同的线宽和状态。移除工作区标题行后，根目录仍提供当前位置信息。

仅增加全局 `overflow: hidden` 会掩盖正文高度或内容访问问题，因此不采用。依赖固定屏幕像素高度会在缩放后失效，因此高度来自应用容器。可选的界面预览使用自包含 HTML 单文件，不新增另一份需求来源。
