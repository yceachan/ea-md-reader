条目 1 提供命令来源，条目 2 提供图标与菜单样式，条目 4 提供窗口布局规则。Android 的设备调试依赖由条目 5 维护，不增加应用内控制台或外部编辑功能。

真实输入测试使用 Electron 的输入事件触发 F12，不能只调用打开函数来证明键位可用。菜单测试选实际菜单项。通过主进程可观察状态确认 DevTools 打开，并比较打开前后 Reader 的实际视口与正文边界。

复用用例连续触发快捷键和菜单，再关闭工具重新打开。空文档、Markdown、HTML 状态各执行一次。原有隔离与只读回归继续通过。控制台自己的 JavaScript 不作为文档得到原生权限的证据。

打包验证使用支持平台的真实产物，确保没有关闭 DevTools 能力。KDE Wayland 用例检查主窗口匹配和初始布局只执行一次，不对控制台做停靠。失败保留命令记录、窗口身份和截图。

完成后更新阶段状态与运行证据，不维护额外 README 索引。验收标准只保留在 raw issue 中。
